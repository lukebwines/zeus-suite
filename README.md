# ZEUS Suite

Repository di sviluppo per l'add-on Home Assistant ZEUS Suite.

## Base iniziale

- Applicazione: ZEUS Suite `1.7.17-rc4-nav1`
- Sorgente di riferimento: `lukebwines/zeus-casa-addons`, ramo `fix/suite-rc4-navigation-20261117`
- Importazione del solo codice necessario alla build, senza i vecchi moduli Paghe e senza dati di produzione.

**Attenzione:** la presenza del codice in questo repository non collega automaticamente l'add-on locale già installato a GitHub. Non effettuare migrazioni o aggiornamenti su Home Assistant prima del collaudo e della verifica di backup/ripristino.
